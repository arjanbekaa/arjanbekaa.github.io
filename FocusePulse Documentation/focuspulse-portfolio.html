✦ Core Features

Nine tightly integrated modules.
One complete picture of your focus.

From real-time activity capture through to behavioral insights, every screen is powered by a distinct service with a clear, testable responsibility.

📊
Real-Time Dashboard
Live focus score, top app breakdown, weekly trend sparkline, and running app overlay — all updated in real-time via a snapshot event system decoupled from the UI thread.
⚡
Focus Score Engine
A weighted formula combining productive time, distraction impact, context switch frequency, and deep work blocks into a single actionable daily score from 0 to 100, with a full breakdown.
🕐
Timeline Visualization
Hour-by-hour layout showing focused, neutral, and distraction lanes. Click any block to inspect session details, context switches, related apps, and targeted recommendations.
💡
Insights Rule Engine
A pluggable rule registry evaluates behavioral patterns — high context switching, low productive ratio, recurring distractors — each returning a confidence score and actionable guidance.
📈
History & Trends
Year-at-a-glance heatmap and monthly trend chart. Switch between Productive Time, Focus Score, Deep Work, or Context Switches as the intensity axis for different views of your history.
🎯
Goals & Rewards
Set daily focus targets per app, earn points for hitting them, and redeem points for user-defined rewards. Full points ledger persisted in the local SQLite database.
🔍
Deep Work Detection
Automatically identifies uninterrupted productive blocks above a configurable minimum duration. Deep work sessions carry extra weight in the focus score calculation with adjustable strictness levels.
📋
Reports & CSV Export
Full date-range queries — week, month, quarter, or custom — with period-over-period comparison, app efficiency breakdown, and one-click CSV export for external analysis.
⚙️
App Catalog & Classification
Discovers all installed applications, lets you classify each as Work, Neutral, or Distraction, and persists those rules so they feed directly into scoring, insights, and goal tracking.

Core Service Layer
ProcessMonitorService
Core Win32 polling loop tracking foreground windows at a configurable interval. Publishes snapshot events to keep the monitoring loop fully decoupled from the UI thread.
FocusScoreService
Weighted scoring algorithm combining productive time, distractions, context switches, and deep work blocks into a deterministic daily score with a full component breakdown.
DeepWorkAnalysisService
Identifies uninterrupted productive sessions above a configurable minimum. Supports adjustable strictness levels and session merge gap settings for precise detection.
DailyInsightService
Orchestrates a registry of pluggable insight rules. Each rule evaluates behavioral metrics independently and returns a scored, prioritized insight card with an actionable recommendation.
BehaviorAnalysisService
Processes raw session data through a filter pipeline — idle exclusion, session validity checks — and produces clean daily behavior summaries consumed across all screens.
HistoryTrendsService
Aggregates week, month, and quarter ranges, computes period-over-period deltas, and prepares data for the heatmap and monthly trend chart on the History screen.

FocusScoreService.cs 
/// Calculates focus score from daily metrics.
public FocusScoreResult Calculate(FocusScoreInput input)
{
    var productive = ScoreProductiveRatio(
        input.ProductiveMinutes,
        input.TotalTrackedMinutes);

    var deepWork = ScoreDeepWork(
        input.DeepWorkBlocks,
        input.DeepWorkMinutes);

    var switches = PenalizeContextSwitches(
        input.ContextSwitchCount,
        input.TrackedHours);

    return new FocusScoreResult
    {
        Score = Math.Clamp(
            productive + deepWork - switches,
            0, 100),
        Breakdown = BuildBreakdown(...)
    };
}
