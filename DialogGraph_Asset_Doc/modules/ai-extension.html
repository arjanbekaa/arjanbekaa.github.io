AI Extension

The optional AI extension generates graph JSON from structured scene specifications and imports the result back into the main dialogue system.

Key files

  • AdvancedAIDialogWindow.cs
  • AIGeneratorController.cs
  • DialogAIBridge.cs
  • DialogPromptBuilder.cs
  • DialogJSONParser.cs
  • LlmProviderDefinitionBase.cs and providers

Workflow

DialogSpecificationSO
    -> DialogPromptBuilder
    -> Provider request
    -> AIGeneratorController
    -> DialogJSONParser
    -> DialogJsonImportBridge
    -> DialogGraph asset

Specification model

The generation spec centers on DialogSpecificationSO and includes conversation depth, character list, environment data, game context, scene summary, tone, and allowed or forbidden actions.

Provider model

The provider abstraction is LlmProviderDefinitionBase, with concrete providers for OpenAI-style chat completions, Gemini, Ollama, and custom JSON APIs.

Main editor entry point

Open Tools > Dialog System > Advanced Dialog Generator.

Reliability layer

DialogJSONParser sanitizes common LLM formatting issues, validates structure, and repairs some graph issues before import.
