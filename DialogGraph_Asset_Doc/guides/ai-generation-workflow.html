Guide: AI Generation Workflow

Generate a candidate dialogue graph from structured data, then import and refine it in the normal graph editor.

Workflow

  1. Create or open a DialogSpecificationSO.
  2. Fill in characters, world context, tone, scene summary, and allowed actions.
  3. Configure DialogAISettings and a provider asset.
  4. Open Tools > Dialog System > Advanced Dialog Generator.
  5. Generate JSON.
  6. Let the import bridge create a DialogGraph.
  7. Review and refine it in the graph editor.

What the AI produces

The extension generates JSON shaped to the graph DTO model. It is not writing directly into the graph asset format; it produces importable graph JSON first.

Best practices

  • keep specs narrow and clear
  • use realistic conversation depth
  • review all action nodes before shipping
  • treat AI output as an authoring accelerator, not the final source of truth
